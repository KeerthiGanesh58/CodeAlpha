# 📊 Superstore Dataset - Exploratory Data Analysis (EDA)

This project presents an in-depth Exploratory Data Analysis (EDA) of the **Superstore Dataset**, providing valuable insights into sales, profitability, customer behavior, and regional performance.

## 📁 Project Structure

- **EDA.ipynb** — Jupyter Notebook containing data loading, cleaning, and comprehensive visual analysis.

## 📊 Analysis Highlights

- ✅ Data Cleaning and Preparation
- ✅ Missing Value Detection
- ✅ Descriptive Statistics
- ✅ Regional Sales & Profitability Analysis
- ✅ Category-wise Sales Breakdown
- ✅ Sales Trend Over Time
- ✅ Customer Spending Patterns
- ✅ Correlation Heatmap (Sales, Quantity, Discount, Profit)
- ✅ Impact of Discount on Profitability
- ✅ Shipping Mode Distribution

## 🛠️ Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
